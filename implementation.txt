1. Core NFC Discovery & Tag Management
#	Feature	Notes
1	Tag poll with technology mask	Selectively enable NFC-A/B/F/V per-poll; currently all-or-nothing
2	Multi-tag field detection	NCI RF_DISCOVER_NTF with more=1; select among N detected tags
3	Explicit tag selection	RF_DISC_SELECT_CMD to pick one of several discovered tags
4	Tag presence check	Ping the activated tag without a full transceive (ISO presence check loop)
5	Tag deselect (sleep)	Put tag to sleep without stopping discovery; libnfc nfc_initiator_deselect_target
6	NCI deactivation modes	Distinguish Sleep / Sleep_AF / Idle / Discovery in RF_DEACTIVATE_CMD
7	RF interface switch	Switch between Frame-RF and ISO-DEP on the same tag; needed for MIFARE Classic + ISO-DEP dual-interface cards
8	Abort in-progress command	Interrupt a blocking poll or transceive; libnfc nfc_abort_command
9	Callback / async API	onTagArrival / onTagDeparture callbacks as alternative to the current blocking pn7160_poll
10	Device capability query	Report which technologies/protocols the NFCC supports; nfc_device_get_supported_modulation equivalent

Priority grouping
Tier 1 — highest impact, completes core reader story
#1–10 (multi-tag, presence, deselect, async API), #17–27 (NDEF write/format), #39–44 (MIFARE Classic), #79 (large data chaining), #126–130 (structured errors)

Tier 2 — expands protocol coverage to libnfc parity
#28–38 (T2T/T3T/T5T/T1T NDEF), #45–62 (NFC-V, FeliCa), #63–74 (NTAG 424 DNA SDM), #75–103 (DESFire EV3 completions), #131–136 (CRC utilities)

Tier 3 — advanced features that surpass both reference projects
#104–116 (P2P / HCE), #117–125 (PN7160 hardware extensions), #137–154 (build/packaging/CLI)

The most strategically valuable items that neither reference project does well are the NTAG 424 DNA SDM stack (#71–73), the DESFire EV3 TMAC/CommitReaderID (#97–99), and the structured error system (#126–128) — these are the differentiators that would make libhcinfc genuinely better than what it replaces, not just equivalent.
